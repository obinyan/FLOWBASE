# Flowbase

Flowbase is a Next.js app for managing leads, tasks, a calendar, inbox, reports, and team settings.

## Run locally

```sh
pnpm install
pnpm dev
```

Open `http://localhost:3000` to use the app. For a production build and server, run `pnpm build` and then `pnpm start`.

The current app stores leads, tasks, calendar events, and inbox data in the browser's local storage. Records are local to that browser until a shared backend is connected.
